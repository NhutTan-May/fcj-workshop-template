The program was completed over **12 weeks** (equivalent to a 3-month internship, from **14/09/2026** to **04/12/2026**). During this time, I gradually progressed from foundational concepts in cloud computing, virtual networking, storage, and databases to advanced topics including operations automation, security, containers, serverless architecture, Data Lake analytics, and Artificial Intelligence / Machine Learning (AI/ML) services on AWS.

The detailed tasks and achievements for each week are presented below:

**Week 1:** [Create AWS Free Tier account, explore AWS Console, and manage costs](1.1-week1/)

**Week 2:** [Create Amazon VPC virtual network, launch Amazon EC2 instance, and configure security](1.2-week2/)

**Week 3:** [Object storage with S3, IAM Role permissions, and Amazon RDS database](1.3-week3/)

**Week 4:** [S3 hosting, VPC Peering, Transit Gateway networking, and Resource Tagging](1.4-week4/)

**Week 5:** [Automated provisioning with CloudFormation, Lambda, and SSO management](1.5-week5/)

**Week 6:** [AWS Security Hub, WAF, KMS encryption, and Docker/ECS containers](1.6-week6/)

**Week 7:** [Build Data Lake, hybrid storage, and cloud cost optimization](1.7-week7/)

**Week 8:** [In-depth cost analysis and application modernization](1.8-week8/)

**Week 9:** [Serverless workflows and event-driven microservices architecture](1.9-week9/)

**Week 10:** [Amazon EKS cluster management, CI/CD pipelines, and serverless frontend](1.10-week10/)

**Week 11:** [Serverless applications with AWS SAM, PaaS deployment, and container hosting](1.11-week11/)

**Week 12:** [Security, Data Lake, QuickSight BI, and Machine Learning wrap-up](1.12-week12/)
